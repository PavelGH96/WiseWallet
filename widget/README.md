# Виджет WiseWallet на айфоне

Виджет показывает, сколько дней вы не вносили расходы, и длину серии —
как Duolingo. Нажатие открывает WiseWallet сразу на форме новой операции.

## Почему это не часть приложения

Apple не даёт веб-приложениям доступа к WidgetKit: PWA на домашнем экране
умеет иконку, полный экран, офлайн и push-уведомления, но не виджеты. В
iOS 27 для веб-приложений на домашнем экране ничего нового не появилось,
так что обойти это нельзя — виджет рисует стороннее приложение, а
WiseWallet выступает источником данных.

Отсюда три части:

```
WiseWallet (PWA)  →  Supabase: ww_user_state.summary  →  Cloudflare Worker  →  виджет на телефоне
   считает факты        несколько чисел и дата          считает «N дней» и тексты    показывает
```

Приложение кладёт в базу **факты**: дату последней записи, длину серии,
свободные деньги. Всё, что зависит от текущего момента, Worker считает в
момент запроса. Иначе после трёх дней молчания в базе лежала бы цифра «0
дней», записанная в последний день, когда приложение вообще что-то
отправляло, — и виджет бодро показывал бы «сегодня записано» ровно тогда,
когда должен напоминать.

---

## 1. База

Выполнить в Supabase → SQL Editor (это уже есть в `supabase_schema.sql`):

```sql
alter table public.ww_user_state add column if not exists summary jsonb;
```

Колонка в той же строке, что и данные, и закрыта той же RLS. Приложение
начнёт её заполнять при первой же синхронизации после обновления.

## 2. Worker

```bash
cd widget
npx wrangler deploy
npx wrangler secret put SUPABASE_URL    # https://xxxx.supabase.co
npx wrangler secret put SERVICE_KEY     # service_role из Project Settings → API
npx wrangler secret put USER_ID         # свой uuid из Authentication → Users
npx wrangler secret put READ_KEY        # длинная случайная строка, придумать самому
```

Ключ можно сгенерировать так:

```bash
openssl rand -hex 24
```

Проверка — открыть в браузере:

```
https://wisewallet-widget.<ваш>.workers.dev/preview?k=<READ_KEY>
```

Должна показаться карточка с серией и цифрами. Без `/preview` та же
ссылка отдаёт JSON — его и будет забирать виджет.

**О сервисном ключе.** Он обходит RLS, поэтому лежит только в секретах
Cloudflare и наружу не уходит. Worker умеет ровно один запрос — прочитать
колонку `summary` одной конкретной строки; ни записи, ни других таблиц.
Ссылку с `READ_KEY` считайте паролем: кто её знает, тот видит эти
несколько чисел. Сменить — заново выполнить `wrangler secret put READ_KEY`.

## 3. Кнопка быстрого добавления

Приложение открывается сразу на форме новой операции по ссылке вида:

```
https://pavelgh96.github.io/WiseWallet/index.html?quick=expense&t=<метка>
```

`t` — одноразовая метка запуска, и она обязательна. Дело в том, что
веб-приложение с домашнего экрана почти всегда уже висит в памяти, и по
нажатию iOS показывает сохранённый снимок, не перезагружая страницу.
Приложение разбирает ссылку ещё и при возвращении в него, а чтобы не
открывать форму каждый раз, когда вы просто переключились на WiseWallet,
оно запоминает последнюю отработанную метку. Меняется метка — значит,
нажали кнопку.

### Ярлык в Shortcuts

1. Новая команда → добавить действия:
   - **Текущая дата**
   - **Форматировать дату** → формат «Пользовательский», строка
     `yyyyMMddHHmmss`
   - **Открыть URL** →
     `https://pavelgh96.github.io/WiseWallet/index.html?quick=expense&t=` и
     следом переменная с отформатированной датой
2. Назвать «Расход», выбрать иконку.
3. Куда поставить — на выбор:
   - **На домашний экран**: поделиться командой → «На экран «Домой»».
   - **В виджет**: виджет «Команды» показывает до четырёх ярлыков.
   - **На экран блокировки** или **на кнопку «Действие»** (если есть).
   - **В Пункт управления** — как элемент управления.

Вторую такую же команду имеет смысл сделать для дохода:
`?quick=income`.

### Что ещё понимает ссылка

| параметр | что делает |
|----------|------------|
| `quick` | `expense` или `income` — обязателен |
| `amount` | сумма, подставляется в форму (`450` или `450,50`) |
| `cat` | категория по названию или идентификатору: `cat=Здоровье` |
| `acc` | счёт по названию или идентификатору |
| `note` | комментарий |
| `whose` | чей расход: `pasha`, `katya`, `sonya`, `family`, `other` |
| `silent` | `1` — записать сразу, без формы (нужен `amount`) |
| `t` | одноразовая метка запуска |

`silent=1` удобен для голоса: «Привет, Сири, такси» → команда спрашивает
сумму и записывает без открытия формы. Без него приложение всегда
показывает форму — вы видите, что именно записываете.

## 4. Сам виджет

Подойдёт любое приложение, умеющее показать JSON по ссылке (Widgy и
подобные). Источник данных — ссылка Worker:

```
https://wisewallet-widget.<ваш>.workers.dev/?k=<READ_KEY>
```

Поля, которые стоит положить в слои:

| поле | пример | о чём |
|------|--------|-------|
| `icon` | `🔥` / `✍️` / `💤` | состояние одним символом |
| `title` | `3 дня без записей` | главная строка |
| `text` | `Серия из 7 дней прервалась` | пояснение помельче |
| `streakText` | `7 дней` | длина серии |
| `daysText` | `сегодня` / `3 дня` | сколько прошло |
| `freeText` | `378 941,45 ₽` | свободные деньги |
| `dueText` | `32 963 ₽` | осталось оплатить в этом месяце |
| `nextText` | `Коммуналка · 5 963 ₽` | ближайший неоплаченный платёж |
| `nextDate` | `2026-11-15` | его дата |
| `mood` | `ok` / `warn` / `alert` | подсказка для цвета |
| `state` | `done` / `due` / `late` / `cold` / `empty` | то же для условий |

Все строки уже готовы к показу — склонения и форматирование сумм делает
Worker. Виджету остаётся положить текст в слой.

Действие по нажатию — запуск той самой команды «Расход» из шага 3.

Если приложение для виджетов умеет показывать веб-страницу, можно вместо
слоёв использовать готовую карточку: та же ссылка с `/preview`.

## Как это ведёт себя

| когда последняя запись | что показывает |
|------------------------|----------------|
| сегодня | 🔥 «Сегодня записано», серия растёт |
| вчера | ✍️ «Сегодня ещё не записывали», серия пока жива |
| 2–3 дня назад | ✍️ «2 дня без записей», серия прервалась |
| 4 дня и больше | 💤 «N дней без записей» |
| записей нет вовсе | ✍️ «Пока ничего не записано» |

День не считается потерянным, пока он не кончился: если сегодня вы ещё не
записывали, серия не обнуляется — так же устроен Duolingo.

## Если не работает

**Виджет пустой или отдаёт ошибку.** Откройте ссылку Worker в браузере с
`/preview`. Ошибка 401 — не совпал `READ_KEY`. Ошибка 502 — Worker не
достучался до Supabase, проверьте `SUPABASE_URL` и `SERVICE_KEY`.

**Показывает «Пока ничего не записано», хотя операции есть.** Колонка
`summary` заполняется при синхронизации. Откройте WiseWallet, дождитесь
синхронизации и обновите виджет.

**Даты сдвинуты на день.** Worker берёт часовой пояс из самой сводки;
если он не определился, можно задать явно параметром:
`?k=<ключ>&tz=Asia/Yekaterinburg`.

**Кнопка открывает приложение, но форма не появляется.** Значит, в ссылке
нет `t` или он не меняется между нажатиями. Проверьте, что в команде
действительно подставляется отформатированная дата, а не просто текст.
